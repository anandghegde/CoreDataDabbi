# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Summary

We pledge to make participation in the CoreDataDabbi community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, colour, religion, or sexual identity and orientation.

Expected behaviour: be respectful and constructive, assume good faith, give and accept feedback gracefully, and focus on what is best for the community.

Unacceptable behaviour includes harassment, insults or derogatory comments, sexualised language or imagery, publishing others' private information, and other conduct that would be inappropriate in a professional setting.

## Scope

This code applies in all project spaces — issues, pull requests, discussions and any other channel the project uses — and when someone represents the project in public.

## Enforcement

Report unacceptable behaviour privately to the maintainer through the contact details on the maintainer's GitHub profile. All reports are reviewed promptly and fairly, and the reporter's privacy is respected. Maintainers may remove, edit or reject contributions that do not follow this code, and may temporarily or permanently ban contributors for behaviour they judge inappropriate, following the enforcement guidelines of the Contributor Covenant 2.1.

The full text of the Contributor Covenant 2.1 at the link above is the authoritative version of this code.
